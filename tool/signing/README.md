# Chiave di firma "di sviluppo"

`clipforge.jks` firma gli APK pubblicati nelle Release di GitHub, così ogni
nuova versione si installa sopra la precedente senza disinstallare.

È pubblica (sta nel repository): va bene per un'app installata a mano, **non**
per il Play Store. Per pubblicare sullo Store crea una chiave privata e tienila
fuori dal repository.
